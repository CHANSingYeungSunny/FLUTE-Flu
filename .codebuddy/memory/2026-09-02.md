## Q6 —— 「MIFlu 多模态注意力是假的 / 论文说谎」这条流传结论已被证伪（重要）
- 该结论硬编码在 `scripts/plot_attention_proof.py` 图注："proves the original MIFlu gain was a LayerNorm statistical shortcut"。该"证明"无效，理由见下。
- **两条支撑统计量均不可作为证据**：
  1. `extract_attention.py` 的 `mean_text_attention == uniform` 对 cross-attn 是**数学恒等式**（softmax 只在文本 key 上归一化 → 均值恒为 1/n_text），零信息量。
  2. `plot_attention_proof.py` 把 `full` 画成 0 文本注意力，只因 `full` 无可 hook 的 cross-attn 模块；原版靠 **GPT-2 因果自注意力**（`hfuse=[htext||htime]`，`miflu_model.py:376`）交互。
- **在原论文架构上实测（HPC 作业 521890）**：时序 query 把 **38.6%** 注意力质量给文本，峰值达机会水平 **34.1×**；去掉文本 LN 后仅 0.526×→0.548×（≈4%）。
- **消融显著性（决定性）**：no_multi（移除全部文本）ΔMSE **+0.7049, p=0.0108 显著**；no_text_ln **+0.3129, p=0.1543 不显著**。文本贡献拆解：LN 占 **44.4%**，**残差 55.6% 不经 LN** → "纯 LN 捷径"不成立。
- **gated_inject 对比有混淆变量**：相对 full 改了**两处**（ModalityAligner **+** `unfreeze_first_k=2`），MSE 2.52→3.04 不能归因于"强制用文本"。
- 架构冻结（仅 PE/LN/LoRA）是**论文 Section IV 公开披露**的，非隐瞒。
- 真实差距：论文 Table V L=24 MSE 1.542 vs 我们 2.5187（1.63×）；Table VIII 四 horizon 均值 1.436 vs 3.1700（2.21×）。但**无作者代码，不能断言论文有误**。
- 已写入报告 Q6（含【订正】3 条）。`plot_attention_proof.py` 图注待用户确认后删除/改写。
