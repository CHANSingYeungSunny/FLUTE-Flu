## 复现差距根因 + 归一化 bug 修复（2026-08-08，重大）
- **根因**：`miflu_model.py` 内部 InstanceNorm + RevIN 用 instance mean/std，而 `make_forecast_figure.py` 又用 train 全局 mean/std 二次反归一化 → 尺度崩坏（L=60 后段甚至出负值 ILI）。`train_miflu.py` 旧版在 RevIN 物理空间算 MSE，违反论文 Section V-B（指标应在 StandardScaler 归一化空间）。
- **修复（已落地 + 本地 CPU 冒烟测试通过 + py_compile 通过）**：
  1. `MIFlu.forward` 现返回 `(y_hat_rev, y_phys, means, stdevs)`：`y_hat_rev`=Inverse RevIN 的 **StandardScaler 空间**（loss/Table V 指标用）；`y_phys`=`y_hat_rev*train_std+train_mean` 再 `clamp(min=0)`（图/CSV 用）。train_mean/std 在 forward 内 `view(1,N,1)` 广播到 (B,N,L)。
  2. `train_miflu.py`：loss/指标在 StandardScaler 空间 `y_hat_rev` vs 归一化目标 `Y`；加 gradient clipping(clip=1.0) + NaN-rep 丢弃（非有限指标的 rep 直接丢弃，绝不存为 best）。
  3. `make_forecast_figure.py`：用 `y_phys` 绘图/CSV；删掉错误常量 0.525/0.393，换 per-horizon `TABLE_V_MIFLU_REF`（L24=1.542/0.726, L36=1.422/0.779, L48=1.414/0.757, L60=1.364/0.719，来自 miflu_ground_truth.json 真实 Table V），仅打印 ratio 不判 pass/fail。
  4. `textual_embedder.py`：task instruction 恢复论文 Appendix Table X **逐字原文**（含 "for the information attached."）。
  5. `PROJECT_STATUS.md §7.2`：诚实标注更新（真实 Table V、bug 根因、修复、成功定义、论文 lr/epochs 未披露故无法逐位复现）。
