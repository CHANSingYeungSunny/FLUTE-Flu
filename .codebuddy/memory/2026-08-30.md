## 踩坑与修复（都会复现，务必记住）
1. **Windows OpenSSH 会吃掉远端命令的引号**：`ssh host 'echo "a  b"'` → 输出 `a b`。
   → 所有远端命令必须**无引号**，因此用 `sinfo -h -N --Format=NodeList,Partition,StateLong,Gres`
   （不带引号、无空格），并用 `^` 之类安全分隔符。
2. **远端 `sed -i s/\r$//` 会毁文件**：引号被吃掉后 bash 把 `\r` 变成 `r`，sed 变成 `s/r$//`，
   把每行结尾的 r 删掉（MD5 不符才发现）。→ **必须在本地 PowerShell 里把 CRLF 转 LF 再 scp**。
3. **`ollama pull/create/rm` 是客户端命令，必须先起 `ollama serve`**。原顺序 pull→serve 导致
   4 个候选全部瞬时失败。
4. **HTTP 代理陷阱（最隐蔽）**：集群设了 `HTTPS_PROXY=http://proxy.cityu.edu.hk:8080`，
   而 `0.0.0.0` 不在默认 `NO_PROXY` 里 → Ollama CLI 把本地 API 调用发给 CityU 代理，
   报无信息量的 "something went wrong"（服务端日志里根本没收到请求）。
   → 修：`NO_PROXY=localhost,127.0.0.1,0.0.0.0,::1`，且 CLI 一律走
   `OLLAMA_HOST=http://127.0.0.1:$PORT`（wrapper `ollama_cli`），服务端仍绑 `0.0.0.0` 供隧道。
5. **`ready.flag` 不能 `touch` 成空文件**：网关判空（`\S`）会永远等不到 → 写入 `serve|ctx|port|ts`。
6. **`squeue -h` 不抑制 `Last update in N seconds ago` 尾部行** → 解析 jobid 必须 `^\d+$`，
   解析 state 必须 `^[A-Z_]+$`（无空格）。
7. **PS 5.1 没有 `File.Move(src,dst,overwrite)` 重载** → 原子写要先删目标再 Move。
8. **`New-Item -ItemType File -Force` 会截断已存在文件** → 曾把用户 PowerShell profile（fnm 配置）
   清空！已修复为只在文件不存在时创建，并已手工还原 profile。
9. PS 5.1 的 `New-Object System.Collections.Generic.List[object]` 在此处报 ArgumentException → 改用普通数组。
