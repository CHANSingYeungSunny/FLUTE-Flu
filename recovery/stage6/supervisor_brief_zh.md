# Stage 6 汇报（八模型统一比较 + A0 诊断）

日期：2026-09-26。**状态：已完成并报告。** 详细报告见 `recovery/stage6/results_report_zh.md`。

---

## 一、这轮做成了什么

在作者 966 行流感数据上，用**同一套冻结协议**拟合并比较了 8 个模型（4 个预测长度 × 3 个随机种子 = 96 次拟合，其中 24 次沿用 A2 已完成的运行，72 次为新增），外加一条「去掉文本通路」的机制控制组，共 108 个模型。所有模型：

- 在**任何 Test 推理之前**完成 checkpoint 锁定（SHA-256 + 验证选模证据）；
- 走**同一条评分代码路径**在 Test 上评价（116 条记录，含 8 条确定性基线）；
- 主指标**从原始预测工件独立重算**验证，最大偏差 `8.9e-16`（机器精度级），**PASS**。

**实际 GPU 消耗 1.10 GPU-h，授权上限 2.3，剩余约 1.2 未花。**

## 二、主要结果

**主指标 `average_MSE_4L`（七变量标准化 Test MSE，越低越好）：**

| 模型 | 分数 | 说明 |
|---|---:|---|
| no-text（去文本） | **1.922** | 机制控制组，非八模型之一；数值最好，但相对 MIFlu 的优势不显著 |
| MIFlu（修正重构） | 2.042 | |
| NLinear | 2.050 | 与 MIFlu **不可分** |
| DLinear | 2.348 | |
| TimeCMA-LLM | 2.670 | |
| PatchTST | 3.920 | 与 iTransformer 不可分 |
| iTransformer | 3.985 | |
| Qwen-Time-LLM | 5.220 | |
| CaLF-LLM | 5.515 | |

因为所有模型跑在同一组 12 个 (长度, 种子) 格上，我们做了**配对检验**，这比直接比均值可靠得多：

| 结论 | 配对证据 |
|---|---|
| **MIFlu 与 NLinear 无法区分** | t = −0.11，MIFlu 只在 5/12 格胜出 |
| **MIFlu 的文本通路没有可确认收益** | 去掉文本后平均更差的方向不成立；MIFlu−no-text 配对均值仅 −0.008（相对 NLinear），且相对 no-text 优势不显著（t = −1.50，5/12）。效应符号随预测长度翻转（L=24/36 变差，L=48/60 略好） |
| **no-text 优于 NLinear，但不是优于 MIFlu** | vs NLinear：t = −2.28，11/12 格胜出；vs MIFlu：t = −1.50，不显著 |
| **三个 LLM 模型全部显著落后于 NLinear** | NLinear − TimeCMA t = −10.9；TimeCMA − PatchTST t = −21.7 |
| 模型容量越大越差 | DLinear < TimeCMA < PatchTST ≈ iTransformer < Qwen < CaLF，逐级显著 |

**通俗地说**：在这份 966 行、Test 只有 193 行的流感数据上，**最简单的线性模型和号称用了文本的 MIFlu 打平，而参数量上万的 LLM 骨干全部明显更差**。至于「去掉文本会不会更好」，数值上是好一点，但**证据不足以断言**。这是一个诚实的负面结果，但方法学上是干净的。

## 三、一个需要导师注意的矛盾（未解决）

我们此前（Stage 2，CPU 审计）判定**作者发布的代码里文本通路是失效的**（文本对输出零影响）。本轮 A0 在 A100 上逐字重放作者代码，却得到相反结果：关掉文本 MSE 0.9685，打开文本 MSE 0.8581，**文本确实在起作用**。

**这两个结论互相矛盾，原因尚未定位。** 本报告不给解释，只并列事实。这直接影响「作者论文的方法到底有没有真的用上文本」这一核心问题，因此**在矛盾解决前，不应对该问题下最终结论**。

作者代码的**其他**缺陷独立成立，与上述矛盾无关：Test 集只覆盖 1 个特征、Test 参与了 checkpoint 选择、LoRA 从未应用、freeze 是空操作、默认只跑 1 个 epoch、PEFT 关闭。

- 10 次重复（而非 3 种子）、2×2 文本/LoRA 矩阵、规范版 PatchTST、区域/小样本研究
- 任何新骨干或新数据集
- **Stage C（独立泛化）仍不可行**：不存在未见过的区间，且不得把旧区间改名来伪造 holdout
- A2 已锁定，**不得重跑或加种子**
