# 03_预测数据_证据/ 里面是什么

**这里只有一样东西重要：`expanded_runs/`**

## expanded_runs/ —— 28 个模型的预测结果（唯一重要）

每次运行一个文件夹，命名规则：`<模型名>_L<跨度>_s<种子>/`

举例：`miflu_L24_s42/` = MIFlu 模型，预测 24 周，随机种子 42

### 文件夹里有什么

| 文件 | 用途 | 能删吗 |
|------|------|--------|
| `pred_*.npz` | **预测值 + 真值**，所有数字都从这里算出来 | ❌ **绝对不能删** |
| `manifest_*.json` | 运行记录（用了什么 GPU、跑了多久） | ❌ |
| `results_*.csv` | 这次运行的指标 | 可重建 |
| `metrics.csv` | 逐项指标 | 可重建 |
| `ckpt/` | 模型权重 | 可重训 |

### 种子编号的含义（重要！）

| 种子 | 用途 | 什么时候用 |
|------|------|-----------|
| `s2021` ~ `s2030` | **复现**论文 Table V（10 次） | 只在"复现成功了吗"那一节 |
| `s42` / `s43` / `s44` | **28 个模型互相比较**（3 次） | 只在"哪个模型最好"那一节 |

**两套种子不能混着比**，这是规矩。

### 模型名对照

| 文件夹前缀 | 模型 |
|-----------|------|
| `miflu_` | MIFlu（论文的方法） |
| `patchtst_` | PatchTST |
| `nlinear_` | NLinear |
| `dnn_` `cnn_` `rnn_` `lstm_` `gru_` | 神经网络类 |
| `qwen25_1_5b_` `ds_r1_distill_*` | LLM 编码器类 |
| `tencent_hunyuan_*` `tencent_contextpilot_*` | LLM 编码器类 |
| `decision_tree_` `random_forest_` 等 | 传统机器学习 |
