## Gap 3 — Innovation Claim

**Current finding (not yet an innovation):** MSE champion (PatchTST) ≠ peak-skill champion (NLinear).

**Three candidates (cheapest first):**

### Option (a): Calibration-aware model-selection rule — 0 GPU-hours
- **Claim:** "Selecting on K&S criterion rather than MSE avoids deploying miscalibrated models, at a quantified accuracy cost."
- **Experiment:** Decision comparison across all 28 arms: MSE-based vs K&S-based selection + cost table.
- **Data:** All on disk (benchmark tables).
- **Cost:** 0 A100-hours (pure analysis).
- **Start date:** 2026-11-03.

### Option (b): Hybrid predictor — 20–60 GPU-hours
- **Claim:** "Combining PatchTST's timing with NLinear's calibration achieves both."
- **Experiment:** PatchTST point forecast + NLinear-style interval recalibration; success = beat NLinear on PTE without losing K&S pass.
- **Cost:** 20–60 A100-hours (new training + recalibration code).
- **Start date:** 2026-11-10 (after rolling origin T3/T6).

### Option (c): Frozen-encoder selection guidance — 0 GPU-hours (RECOMMENDED)
- **Claim:** "Frozen LLM representations do not automatically improve epidemiological forecasting; encoder family selection matters and has a quantifiable parameter cost."
- **Experiment:** 11-arm analysis: which families (Qwen/DeepSeek/Tencent) help vs hurt, parameter cost scaling, Llama-8B vs Qwen-7B architecture comparison (near-equal scale).
- **Data:** 132 cells on disk, aggregation now complete.
- **Cost:** 0 A100-hours (analysis only).
- **Start date:** 2026-11-03.
