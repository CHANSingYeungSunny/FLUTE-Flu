## 2. Fix applied (proven, not assumed)

The model is **provably channel-independent**: the `author_faithful` forward pushes
each variable into the batch dimension and applies the shared flatten head
`Linear(num_patches*D, L)` per variable. Therefore `N` is a *packing* parameter
only and never changes the parameters.

`hpc_experiments/smoke_single_var.py` demonstrates:

- `state_dict` keys and shapes identical for `N=1` and `N=7` (0 mismatches);
- `load_state_dict` from an N=1 model into an N=7 model: OK;
- `max | N=1 looped − N=7 packed | = 8.0e-07` ≈ 0 on identical weights;
- one real optimiser step with a 16-sample single-variable batch: OK.

Change in `scripts/train_miflu.py`:
- `forward_all_vars()` — feeds all 7 variables to an N=1 model by looping channels;
- `train_L()` builds the model with `N=1` when `MIFLU_SINGLE_VAR=1` (default).

Consequence: the only thing that change #15 actually alters is the **effective
batch size** (16 (window, variable) pairs per step = the author's composition,
instead of 112 pairs from 16 windows). It does not alter the model.

### Correction to an earlier claim

The 2026-10-31 session reported "all 4 steps PASS, PTE 1.0 wk, PIE 3.9%" for
L24/seed42. That figure was computed on a "7-variable aggregate" built as the
**plain mean of the seven de-normalized variables**, which is dominated by `OT`
(train mean 493,629) and `ILITOTAL` (9,440) over the percentage variables
(~1.7–3.7). The curve was therefore essentially the `OT` curve and the PTE/PIE
were not measuring ILI peak behaviour.

The two sound options now reported side by side:

1. **`% WEIGHTED ILI`** — the series Kramer & Shaman actually use. De-normalized
   to percent.
2. **7-variable aggregate normalised by each variable's training mean** (dimensionless,
   "× training mean"), so percentages and counts contribute on equal footing.

Also corrected: v1 used a single global `argmax` over the whole 170-week test span,
which spans ≈3 influenza seasons, producing nonsense PTE of 100+ weeks. v2 detects
each epidemic peak in the ground truth and matches the prediction's strongest
response within ±8 weeks, then averages over seasons.

Result (L24, median over seeds, `% WEIGHTED ILI`): non-LLM pass 25% at week 1,
LLM pass 8.3%; PIE median 30–45% — almost everything FAILS the ≤25% criterion.
This is consistent with the project's long-standing "MIFlu 15/36 peak" finding and
contradicts the earlier "all PASS" claim.
