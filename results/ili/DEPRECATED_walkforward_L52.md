# DEPRECATED — ChatTime-style L=52 Walk-Forward Results

**DO NOT USE THESE AS CONCLUSIONS.**

The files below were produced by the **ChatTime-style L=52 walk-forward**
protocol (`scripts/chattime_variant/generate_walkforward.py`), which is a
**different evaluation scheme** from the MIFlu paper protocol:

| | This directory (DEPRECATED) | Paper protocol (CURRENT) |
|---|---|---|
| Horizon | single L=52, rolling stride=52 | `L ∈ {24,36,48,60}` independent runs |
| Split | 70:10:20, test=rolling windows | 70:10:20, per-L test split |
| Output | `miflu_fulltest_walkforward.csv` | `data/results_miflu_paper_protocol_*.csv` |
| Conclusion status | ⚠️ DEPRECATED | ✅ AUTHORITATIVE |

Because the two protocols define train/test differently, numbers here are
**not comparable** to the paper's Table V even if the model is correct.
