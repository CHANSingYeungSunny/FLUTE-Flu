# 导师会议简报（中文）— Wave-1 分析

**一句话结论：** 在 frozen 选择规则下，Wave-1 冠军是 `gpt2_miflu`（平均 MSE 4L = 0.771），最佳非 LLM 是 `nlinear`（1.070）；但"LLM 打赢经典模型"这个叙事需要**谨慎**——LLM 家族整体反而更差，且冠军在短期的优势被一个零参数的季节基线抹平。

---

## 三条必须让导师知道的事实

### 事实 1：胜利属于"一个模型"，不是"整个 LLM 范式"

| 家族 | 平均 MSE 4L |
|---|---:|
| 非 LLM 组（nlinear / dlinear / patchtst / itransformer） | **1.142** |
| LLM 组（gpt2_miflu / qwen / calf / timecma） | 1.243 |

配对 t = −11.15，**p = 1.44×10⁻⁶**。非 LLM 家族整体**显著更准**。LLM 的冠军地位完全由 `gpt2_miflu` 单点撑起——其余三个 LLM 全部不如最佳非 LLM。论文如果写成"LLM > 经典预测器"会被审稿人抓住。

### 事实 2：短期上，一个"重复去年"的季节基线就打败了冠军 LLM

| 预测期 | seasonal_naive（0 参数） | gpt2_miflu |
|---:|---:|---:|
| L24 | **0.719** | 0.732 |
| L36 | **0.732** | 0.778 |
| L48 | **0.746** | 0.760 |
| L60 | 0.885 | **0.813** |

`seasonal_naive` 在 L24/L36/L48 三期都**更准**。这意味着 `gpt2_miflu` 在短期的绝对精度，大部分是"季节性"的功劳，而不是文本/LLM 的增量。这是最需要向导师强调的诚实性要点。

### 事实 3：消融显示——文本里唯一有用的是"数据集描述"，LoRA/多模态几乎没用

| 消融（移除的组件） | 相对伤害 | p 值 |
|---|---:|---:|
| 数据集信息 | **+12.85%** | **0.004** |
| 输入变量描述 | +5.80% | 0.079 |
| 任务指令 | +2.82% | 0.40 |
| 多模态融合 | +1.95% | 0.47 |
| LoRA | +0.26% | 0.95 |

创新点（LoRA 微调 + 多模态对齐）在统计上**无贡献**。有用的只是 prompt 里描述 ILI 数据集的那段文字。

---

## 需要和导师讨论 / 决策的问题

1. **叙事定位：** 论文应该定位为"`gpt2_miflu`（一个具体的 LLM 适配器）优于基线"，而不是"LLM 方法优于经典方法"。是否同意这个收敛？
2. **季节基线：** `seasonal_naive` 这么强，是否要把它提升为主表里的正式基线（而不是附录）？
3. **创新点危机：** 消融显示 LoRA + 多模态增量≈0。论文的"创新贡献"需要重新论证——是保留并解释（机制上文本信息来自数据集描述），还是调整故事线？
4. **代价透明度：** gpt2_miflu 是 nlinear 的 409× 参数、28× 训练时间。要不要在论文里直接列这个权衡表？
5. **延期对照（Wave-2）：** 18 个负对照还没跑，是否要等它们完成再定稿结论？
