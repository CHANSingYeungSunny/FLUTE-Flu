# 导师会议简报（中文）—— 最终 Test/Holdout 结果

**一句话结论：** Wave-1 验证集冠军 `gpt2_miflu`（0.771）**没有**泛化到留出的 COVID 时代 Test 窗口——在那里，简单线性模型 `nlinear`（2.739）显著优于它（3.051，p = 4.0×10⁻⁴）；两个模型仍优于零参数的 `seasonal_naive` 基线（4.279），后者在分布偏移下崩盘。

---

## 导师必须看到的三件事

### 事实一：验证集排序在 Test 上反转

| 模型 | 验证集 avg MSE 4L | Test avg MSE 4L | 95% CI（Test） |
|---|---:|---:|---:|
| `nlinear` | 1.070 | **2.739** | [2.731, 2.747] |
| `gpt2_miflu` | **0.771** | 3.051 | [2.922, 3.179] |
| `seasonal_naive` | 0.771 | 4.279 | 不适用 |

冠军的验证集优势是窗口特异的。Test 上 `nlinear` 在**全部四个时长**都更好（L24 +0.413，p = 0.004；L36 +0.477，p = 0.004；L48 p = 0.055；L60 p = 0.175）。确认性检验 C1（配对 t = 5.46，p = 4.0×10⁻⁴，Holm 校正）拒绝"两者相等"的假设。

### 事实二：季节性不是预测——基线在 Test 上崩盘

| | 验证集 | Test | 差距 |
|---|---:|---:|---:|
| `seasonal_naive` | 0.771 | 4.279 | **+3.51** |

验证集上 `seasonal_naive` 与 `gpt2_miflu` 打平——它的成功只是记住了 2016–2018 强季节时段的形状。在 COVID 时代 Test 窗口上，它以巨大差距成为最差模型，峰值强度误差高达 124%。这是本研究最清晰的证明："重复去年"不是预测。

### 事实三：`nlinear` 是 Test 上最好的运维模型（而且最简单）

| | 参数量 | Test avg MSE 4L | Test PIE（峰值强度） |
|---|---:|---:|---:|
| `nlinear` | 2,520 | 2.739 | 9–21%（命中 75–94%） |
| `gpt2_miflu` | 1,030,056 | 3.051 | 41–62% |

对疫情检测真正重要的峰值*强度*预测而言，`nlinear` 大幅领先。两个学习模型仍优于基线（C2 p = 4.6×10⁻⁹，C3 p = 7.7×10⁻²¹）。

## 与导师讨论 / 决定的问题

1. **最终叙述框架：** 论文标题是否应为"简单线性预测器在留出数据上优于 LLM"，而非任何"LLM 优越"主张？
2. **冠军身份：** 冻结的 Wave-1 选型作为*验证集*结果成立，但 Test 赢家是 `nlinear`。如何措辞"冻结选型"与"最终推荐"，使两者互不矛盾？
3. **`seasonal_naive` 作为正式基线：** 其验证集 vs Test 的崩盘是最具说服力的结果——是否将其提升为主表基线？
4. **成本论证：** `nlinear` 参数量少 409 倍、训练快约 28 倍，如今 Test 上还更准确。LLM 机制在最终论文中是否还保有存在理由？
5. **局限性措辞：** Test 窗口是单个连续 COVID 时代窗口——确认我们明确写出"分布偏移与 COVID 混淆"，而非过度声称稳健性。
