## 1. 聚合策略（Q1）

**历史表述：** `fixed_step/step=0` 的 z 空间数字（如 L24 step0=3.1173）被当作"修复后的主结果"。

**修正：**
- 该 step 扫描来自**更宽切分（4368 行，2018–2021）**，窗口至 2021-07-18，**不是 Track C**。
- Track C 的正确做法是：保留 **L24/L36/L48/L60 各自分别计分**，`average_MSE_4L` 只是显式声明的事后汇总，**不替代**单独 horizon。
- 终版报告必须展示全部四个 per-horizon 结果，不得用 step=0 单点数字替代主评分器。

## 2. 时间对齐与 COVID（Q2）

**历史表述：** "测试集覆盖 2018–2021 COVID 期；2021-02-07 出现幻觉式峰值高估（pred=30524 vs gt=14108）。"

**修正：**
- Track C Test = **2016-10-25 → 2020-06-30**，仅末 **26 周**（2020-01→2020-06）含 2020 春季 ILI 骤降；**2021 峰值不在 Test 窗口**。
- 因此"2021 幻觉峰"这一结论属于旧更宽切分，**不适用于 Track C**，必须移除。
- 改用诚实表述：Track C Test 覆盖 2016–2020，仅末尾含 2020 春季 ILI 崩塌；8/8 模型在 lag0 对齐（nlinear 3 格有亚周相位滞后，属真实预测属性，非索引错位）。
- 如需讨论分布外行为，措辞应为"分布漂移下的峰值高估/方向一致性"，**不得**称"已证实的幻觉"。

## 5. PTE/PIE 与停止准则（Q5）

**历史表述：** 文献准则 PTE≤1周&PIE≤25%（Kramer&Shaman 2019）；项目自定义 PTE≤2周&PIE≤20%（注明非文献）。

**修正：**
- 文献准则与项目自定义准则**必须分开标注**，不得把 20% 当作论文阈值。
- Track C 实测（文献准则）：NLinear 36/36（100%）、DLinear 31/36、MIFlu 15/36（41.7%）。
- **MSE 冠军（MIFlu）不是峰值冠军**：NLinear 峰值命中 100%，MIFlu 仅 41.7%——两者是不同问题，分别报告。
- 停止准则（Track S 早停 vs 固定 20 epoch）实测**等价**：12 次拟合 11 次完全相同，仅 1 次因早停回滚到局部谷偏差 +0.144。故停止准则不影响冠军排名。
