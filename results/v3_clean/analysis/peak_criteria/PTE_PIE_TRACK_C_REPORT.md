# PTE / PIE — Track C 八模型峰值验收结果（文献口径）

生成日期：2026-10-08　·　数据：Track C strict-966 Test　·　轨道：Track C（冠军赛契约）

---

## 1. 采用的口径

按 2026-10-08 决定，采用**文献口径**，不使用此前的自定义数值：

| 项 | 采用值 | 来源 |
|---|---|---|
| PTE（峰值时间误差） | \|预测峰值周 − 真实峰值周\|，**≤ 1 周** | Kramer & Shaman, 2019 |
| PIE（峰值强度误差） | \|预测峰值 − 真实峰值\| / 真实峰值，**≤ 25 %** | Kramer & Shaman, 2019 |
| 判定方式 | **逐峰**判定；PTE 与 PIE **同时**满足才算命中 | 同上，与 CDC FluSight 挑战赛同口径 |

**文献**：Kramer SC, Shaman J. *Development and validation of influenza forecasting for 64 temperate and tropical countries.* PLOS Computational Biology, 2019. DOI: 10.1371/journal.pcbi.1006742

**重要**：判定是**逐峰**的，不是取跨峰均值。此前 `miflu_verdict_table_L24.md` 用均值（PTE 1.500 / PIE 19.490）判定为 accurate，但其中第 2 个峰的 PTE = 2 周，按文献口径**不合格**。均值化会把不合格的峰掩盖掉，本次不采用。

此前使用的自定义阈值（PTE ≤ 2.0 周 / PIE ≤ 20.0%）已**废弃**；若日后引用那批数字，必须标注为「本课题自定义，非文献标准」。

## 2. 计算方法

| 参数 | 值 | 理由 |
|---|---|---|
| 预测序列构造 | `forecast_lead = 1`（提前 1 周，即 step 0） | 与问题一「不跨 lead time 混合」一致 |
| 变量 | ILITOTAL（feature_index = 4） | 患者计数，峰值强度的载体 |
| 单位 | **物理患者数**（z → physical） | PIE 是相对误差，必须在物理量上算；在 z 空间算等于除以（值 − 均值） |
| 缩放器 | mean 9439.84 / scale 9003.15，仅用 train rows [0, 676) 拟合 | 防泄漏 |
| 峰检测 | 贪心取极大值，最小间隔 **40 周**，且须超过序列**均值** | 流感季为年度周期；用中位数会把淡季小凸起（21k–25k，中位数 18k）误判为峰 |
| 峰匹配窗口 | ± 2 周 | 沿用项目既有约定 |
| 序列长度 | L=24:170 周 / L=36:158 / L=48:146 / L=60:134，均自 Test 第 773 行起 | 随 L 递减 |

**峰检测修正记录**：最小间隔取 30 周、阈值取中位数时，每格检出 5–6 个峰且出现 16 周间隔（淡季噪声）。改为 40 周 + 均值阈值后，L=24 检出 3 个峰，间隔 53 / 51 周 —— 与年度流感季一致。

## 3. 结果

**逐峰命中率（12 格 = 4 horizon × 3 seed，每格 3 峰，共 36 峰/模型）**

| 排名 | 模型 | 命中 / 总峰 | 命中率 | mean PTE（周） | mean PIE（%） |
|---:|---|---:|---:|---:|---:|
| 1 | **NLinear** | **36 / 36** | **100.0 %** | 0.28 | **3.14** |
| 2 | DLinear | 31 / 36 | 86.1 % | 0.92 | 17.72 |
| 3 | **MIFlu** | 15 / 36 | **41.7 %** | **0.29** | **25.00** |
| 4 | Qwen-Time-LLM | 1 / 36 | 2.8 % | 0.96 | 36.33 |
| 5 | TimeCMA-LLM | 0 / 36 | 0.0 % | 1.38 | 50.44 |
| 6 | PatchTST | 0 / 36 | 0.0 % | 0.67 | 66.61 |
| 7 | iTransformer | 0 / 36 | 0.0 % | 0.72 | 66.16 |
| 8 | CALF-LLM | 0 / 36 | 0.0 % | 0.93 | 81.25 |

**直接回答「哪个模型满足条件（PTE ≤ 1 周 且 PIE ≤ 25 %）」：**

> **NLinear**，36 个峰全部命中（100 %）。其次是 **DLinear**（86.1 %）。
> **MIFlu 只有 41.7 %**。

## 4. 关键发现：MSE 冠军 ≠ 峰值冠军

| 模型 | Test MSE 排名 | 峰值命中率排名 |
|---|---:|---:|
| MIFlu | **1**（1.8652） | **3**（41.7 %） |
| NLinear | 2（2.0495） | **1**（100.0 %） |
| DLinear | 3（2.3478） | 2（86.1 %） |

三条观察：

1. **MIFlu 的时间定位是最好的**（PTE 0.29 周，与 NLinear 0.28 并列最佳），说明它**找准了峰值出现在哪一周**。
2. 但 **MIFlu 低估峰值强度**（PIE 25.00 %，正好压在阈值上），导致逐峰判定只有 41.7 % 命中。
3. **五个较复杂的模型（TimeCMA / PatchTST / iTransformer / CALF / Qwen）峰值命中率接近 0，PIE 达 36–81 %** —— 严重削峰。这与「以 MSE 为训练目标 → 向均值回归 → 削平极值」的机制一致。

**这不是矛盾，而是两个不同的问题**：MSE 由全部 170 周的拟合决定，而 3 个峰只占 170 周中的 3 周，对 MSE 贡献极小。一个模型可以在绝大多数周拟合得更好（MSE 更低），同时在极少数峰值周低估幅度（PIE 更高）。**两个指标测的不是同一件事，必须分开报告。**

## 5. 稳健性

9 组参数组合（最小间隔 40 / 52 × 振幅阈值 mean / mean+0.5sd / median × 匹配窗口 ±2 / ±4 周）下，**模型排序完全一致**，无一次变更：

```
nlinear > dlinear > miflu > qwen_time_llm > timecma_llm > patchtst > itransformer > calf_llm
```

详见 `PTE_PIE_SENSITIVITY.txt`。MIFlu 的 mean PIE 在 25.00–25.06 % 之间浮动，恰好处于阈值边界，因此**其 41.7 % 这一具体数值对参数略敏感，但「明显低于 NLinear 与 DLinear」这一结论是稳健的**。

## 6. 对问题五三条的逐条答复

**(1) 指标定义与阈值** —— 已落地。PTE / PIE 定义与「PTE ≤ 1 周、PIE ≤ 25 % 判定命中」均挂到 Kramer & Shaman (2019) 可核实 DOI，判定改为逐峰。

**(2) 训练停止机制** —— ⚠️ **此处有一个必须披露的偏差。**

Track C 的八个模型**都没有使用 patience 5–10 的早停**。实测：

```
miflu_strict966_train.py:158    for ep in range(a.epochs):     ← 固定 20 epoch
miflu_strict966_train.py:140    patience=3                     ← 仅传参，未被调用
stage5_a2/execution_ledger.md   "early_stopping": "disabled; fixed 20 epochs"
```

实际做法是**固定 20 个 epoch + 事后取验证集最优 checkpoint**，这与「patience 触发停止」是不同的机制，虽然**意图相同**（只用验证集、绝不碰 Test）。

**已实测补充（Track S）**：为给出真实测量而非口头近似，另设独立轨道 S1，在**完全相同的 MIFlu 配置**上仅把停止规则改为 patience=5 验证早停 + 回滚最优权重（种子 42/43/44、4 个 horizon、12 次拟合，约 1.2 GPU-h，rc 全 0）。结果：

- **12 格中 11 格与 Track C 冠军结果完全相同（至小数点后 6 位）**；
- **唯一例外 L60/seed43**：Track C = 1.880344，早停 = 2.024601（差 +0.144）—— 早停在该格卡在 epoch 3 的**局部验证谷**并回滚，而固定 20 epoch 选出的是验证略差、Test 更好的更晚 epoch；
- 均值：Track C 1.865155 vs 早停 1.877177（+0.64 %）。

**结论**：两种停止规则对该模型与数据**结果等价**，不改变冠军排名。早停主要节省约一半算力，而非改变模型。详见 `S1_EARLYSTOP_PROTOCOL.md` 与 `S1ES_VS_TRACK_C.csv`。

**报告中对该偏差的诚实标注（推荐措辞）**：
> 训练采用固定 20 epoch + 验证集最优 checkpoint 选择。受控补充实验（Track S）以 patience=5 早停重跑同一配置，12 格中 11 格与冠军结果数值相同，1 格因早停回滚至局部验证极小点而略差（+0.144）；两停止规则结果等价，不影响冠军赛排名。两者均仅用验证集选点、Test 只读一次。

**(3) 两层标准配合** —— 已按此执行。训练停止只看验证集；PTE / PIE 在模型训练**结束后**于 Test 上计算，作为验收判据，**从未**作为触发停止的信号。本次 PTE/PIE 完全是离线对已保存预测的重算，未触发任何重新训练。

## 7. 诚实限制

1. **峰值样本量小**：每模型 36 个峰（12 格 × 3 峰）。Test 覆盖仅约 3 个流感季（170/158/146/134 周），不足以支撑强结论。
2. **未做显著性检验**，因此不对「NLinear 显著优于 MIFlu」作统计主张。
3. **MIFlu 的 PIE 恰好在 25 % 边界**（25.00–25.06 %），个别峰的判定对该阈值敏感。
4. **本结果不改变 Track C 冠军**。冠军契约是 Test MSE，MIFlu 仍是冠军（1.8652）。PTE/PIE 是**另一套验收标准**，两套标准各自独立报告，不得互相替换。
5. 峰检测的最小间隔与振幅阈值是本课题工程选择，**非文献标准**，已在 §2 说明并做了敏感性分析。
