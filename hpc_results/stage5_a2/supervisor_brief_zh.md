# Stage 5 / A2 导师简报（作者 966 行受控比较）

日期：2026-09-26（Asia/Hong_Kong）。授权来源：用户本轮明确授权；**不代表导师已批准**。
完整报告：`recovery/stage5/results_report_zh.md`。补充表格：`recovery/stage5/results_tables_zh.md`。账本：`recovery/stage5/execution_ledger.md`。

## 1. 做了什么

在**作者发布的 966 行数据**上，按一套先冻结、后执行的协议，比较三个模型（修正重构版 MIFlu、去掉文本通路的 no-text 消融、线性基线 NLinear）在 4 个预测步长（L=24/36/48/60）× 3 个种子上的表现，共 **36 次独立拟合**，加 **8 条确定性基线**评价，然后在**锁定全部 checkpoint 之后**统一对 Test 评分。

数据切分 676 / 97 / 193；T=104；固定 20 epoch、Adam lr=5e-4、无学习率调度、无 early stopping；每个 run 用**自己的验证集**七变量标准化 MSE 选 checkpoint，**训练全程不接触 Test**。

## 2. 结果（主指标 `average_MSE_4L`，七变量标准化 MSE，越低越好）

| 模型 | average_MSE_4L |
|---|---:|
| **no-text（去掉文本通路）** | **1.922** |
| MIFlu（文本通路开启） | 2.042 |
| NLinear | 2.050 |
| Seasonal Naive | 2.269 |
| Last Value | 7.166 |

**要点：在这个协议下，去掉文本的版本最好；MIFlu 与一个线性基线基本分不出高下。**

## 3. 可以说 / 不可以说

**可以说：**
- 文本通路没有带来可确认的预测收益。在预先指定的主指标上 no-text 更好 6.2%，但差距主要由 L=24 拉大；到 L=48/60 两者互有胜负。
- MIFlu 与 NLinear 的差距（0.008）比单个 L 上 3 个种子的波动（0.03–0.31）小一个数量级，无法区分。
- 三个学习模型都远好于 Last Value，与 Seasonal Naive 大致同档或更好。
- 误差集中在 AGE 0-4 / AGE 5-24 两个通道；weighted ILI 通道本身预测得并不差。

**不可以说：**
- 不能说"文本确定有害"——按种子配对后差异的符号在 L 之间翻转，标准差与均值同量级。
- 不能说"MIFlu 与 NLinear 等效"——只能说在本协议下无法区分。
- 不能说已复现或已推翻论文——**A0（作者发布代码逐字重放）本轮未执行**，这是修正重构，不是复现。
- 不能把 3 个种子的波动当作时间泛化不确定性或重复实验。
- 不能把本轮数值与旧 1,025 行项目结果放进同一排名（划分、rep 数、选模方式、窗口规则都不同）。
- 文本能让输出发生变化（预检已验证），这与文本能提升性能是两件事，本轮分别确认。

## 4. 协议执行与必须披露的偏离

**做得对的部分：**
- 修正了一个实质缺陷：原代码按"目标起点"把窗口归入划分，L=60 时**验证目标会越界进入 Test**，而验证 MSE 正是选模型依据。本轮全程使用"目标块必须完整落在所属划分"的严格规则。
- 36 个 checkpoint 在任何 Test 推理之前锁定（含完整 SHA-256），锁定副本另存。
- 全部 44 条评价走同一套指标代码；并用一个**不导入任何模型代码**的独立脚本，只从预测张量、Test origin 清单与 scaler 重算主指标，逐格比对，最大偏差 4.44e-16，**通过**。

**偏离 / 异常（已全部记录在案）：**
1. 8 条基线的 Test 数值产生于 no-text 后两个种子拟合**之前**（不符合协议字面顺序）。但当时不存在任何学习模型的 Test 数值，基线数值不可能影响选择；统一评分作业在完整锁定后重算基线，数值逐位相同。报告采用的基线数值出自完整锁定之后。
2. 上一轮 no-text 的 4 个 L 只完成 seed 42，另两个种子被一个有缺陷的 resume 判据静默跳过（作业显示 COMPLETED 但实为空跑）。本轮修复判据后**只补做缺失的 8 个拟合**，seed 42 与其余 28 个已完成拟合原样复用（SHA-256 未变）。
3. 统一评分作业首次运行因一个 NLinear 推理的代码缺陷失败，最小修复后重跑成功，指标代码路径未变。
4. no-text 与 NLinear 的 `best_epoch` 未能留证（逐 epoch 日志被作业封装的 `tail -40` 截断 / 从未记录）。选模型实际使用的 `best_val` 对 36 个 run 全部齐备并已锁定。曾尝试从日志恢复但会错误归属 seed，**已丢弃**而不发布。
5. A0 仍为 BLOCKED，未执行。
6. 作者 Test 早已暴露，本轮只是协议冻结后的回顾性评价，**不是新的独立泛化 Test**；没有任何新 holdout 被打开。
