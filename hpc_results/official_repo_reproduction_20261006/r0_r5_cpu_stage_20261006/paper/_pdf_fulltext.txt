MIFlu: Large Language Model-Based
Multimodal Inﬂuenza Forecasting Scheme
Jaeuk Moon

Abstract—In order to minimize the impact of inﬂuenza
on public health, accurate early forecasting is essential.
Various deep-learning-based models have been proposed
to predict future inﬂuenza occurrences by capturing tempo-
ral/regional patterns from past occurrence time-series data.
However, the prediction performance of these unimodal ap-
proaches is limited because they extract knowledge only
from collected data, and users cannot input contextual in-
formation and domain knowledge to them. Recently, large
language models (LLMs) have demonstrated the potential
to improve prediction accuracy by linking contextual text
information to time-series predictions. In this paper, we
propose MIFlu, a multimodal inﬂuenza forecasting scheme
that can fuse contextual text information to time-series in-
ﬂuenza occurrences using two LLMs. It ﬁrst extracts text
embeddings from the user’s text prompts that contain con-
textual information using a text-embedding LLM. Then, MI-
Flu fuses the text embeddings and time-series embeddings
and uses the fused embeddings to predict future occur-
rences using a forecasting LLM. In extensive experiments
using public national/regional inﬂuenza datasets, MIFlu
outperforms other predictive models, improving prediction
performance by up to 26.2% compared to state-of-the-art
models. We also analyze the effect of various textual input
embedders, hyperparameters, and the amount of training
data on forecasting accuracy.
Index Terms—Artiﬁcial neural network, deep learning, ILI
prediction, large language models, multimodal forecasting.

II. RELATED WORK
Regional inﬂuenza forecasting predicts future inﬂuenza oc-
currences in multiple regions using only historical occurrence
data from those regions. Here, exogenous data such as internet
search (e.g., Google Trend) or weather data are not utilized
because of their limited availability and reliability [3], [4],
[5]. Due to the nature of infectious diseases, which spread
rapidly across regions over time, researchers have focused on
jointly capturing temporal and regional patterns of inﬂuenza
outbreaks [10]. To achieve this, deep-learning models such as
recurrent neural networks (RNNs) and GNNs have been widely
used. RNNs and their variants, such as long short-term memory
(LSTM) and gated recurrent units, are specialized for capturing
temporal patterns. For example, Wu et al. [4] utilized an RNN
to learn temporal patterns in speciﬁc regions and adopted a
convolutional neural network (CNN) to fuse temporal patterns
in multiple regions to capture regional patterns. They also added
residualconnectionsbetweentimesequencestoavoidoverﬁtting
during the training process. In contrast, GNNs consider each
region as a graph node and can effectively represent regional
patterns with an adjacency matrix. For example, Deng et al.
[3] ﬁrst captured the temporal patterns of nodes using a tem-
poral CNN and utilized these patterns in a node feature matrix.
Subsequently, they used an RNN to extract features from each
node and utilized these features to construct an adjacency matrix
that represents regional patterns. The node feature matrix and
adjacency matrix were incorporated using a GNN to predict
future inﬂuenza occurrences.
Self-attention mechanisms can also be used to capture re-
gional patterns by assigning higher weights to relatively impor-
tant components in the input data. For example, Jung et al. [5],
[10] proposed the inﬂuenza forecasting model SAIFlu-Net using
this mechanism. They ﬁrst used LSTM to obtain the temporal
patterns of each region and used these patterns as a query
and key for each region. The self-attention mechanism then
calculated regional patterns for regional inﬂuenza forecasting.
They demonstrated that SAIFlu-Net was superior to previous
regional inﬂuenza forecasting models, including CNNRNN and
Cola-GNN.
Transformers, ﬁrst introduced by Vaswani et al. [11], have
recently been used for multivariate time-series forecasting. The
transformer architecture consists of two modules that rely heav-
ily on self-attention: an encoder that understands the input
data and a decoder that generates an output sequence based on
knowledge from the encoder. The transformer [11] is suitable for
capturing long-term temporal patterns due to its self-attention,
which can capture temporal patterns over the entire period of
the input data. Therefore, researchers have used transformers
and their variants for long-term forecasting, including national
inﬂuenza forecasting which predicts multiple different vari-
ables that represent the inﬂuenza occurrence of one country.
Kitaev et al. [12] proposed the long-term forecasting model
Reformer, which was based on a transformer. They utilized
locality-sensitive hashing to perform an approximate nearest
neighbor search, which led to a more memory-efﬁcient trans-
former. Wu et al. [13] also modiﬁed a transformer to develop a
decomposition forecasting architecture. They decomposed the
input time series into patches divided by the time axis and
replaced self-attention with an auto-correlation module. This
allowed the model to capture seasonal and cyclic temporal
patterns.
Recently, LLMs based on transformer architectures pre-
trained on large-scale text databases have demonstrated remark-
able performance in a variety of natural language processing
(NLP) tasks, attempts have been made to utilize LLMs for
time-series forecasting by aligning time-series features with text
features.Forexample,Zhouetal.[9]provedthatﬁne-tuningonly
the ﬁrst several layers of the pre-trained GPT2 with an added
output layer appropriate for the downstream task can outperform
existing transformer-based models in various time-series tasks
such as long- and short-term forecasting, classiﬁcation, and
anomaly detection.
These previous approaches are unimodal inﬂuenza forecast-
ing models that are trained solely to predict future values by

B. LLM
Most LLMs are based on a transformer that relies on a
self-attention mechanism. In general, the transformer structure
consists of an encoder and a decoder, leading to two main types
of LLM: autoencoding models based on an encoder (e.g., BERT
[15]) and autoregressive models based on an decoder (e.g., GPT
[16] and a LLaMA [17]). Autoencoding models are widely used
in downstream tasks in which understanding the input text is
important, such as word/document classiﬁcation or sentiment
analysis, while autoregressive models aim to generate text that is
likely to follow the input text. Autoregressive models are trained
on large volumes of unlabeled text data using self-supervised
learning, in which they learn to predict the next masked word
as the label of the input text. This predictive ability generated
during the training process in causal language modeling makes
LLMs suitable for time-series forecasting tasks [18].
C. Parameter Efﬁcient Fine-Tuning
As LLMs are pre-trained with diverse and large amounts of
data, ﬁne-tuning is essential to utilize LLM for a speciﬁc task.
However, ﬁne-tuning all the layers of LLMs on small, domain-
speciﬁc dataset can make LLM forget most of the pre-trained
knowledge during the ﬁne-tuning process [22]. This problem is
called catastrophic forgetting, which raises the importance of
new training methods.
PEFT[23]hasemergedasaneffectivesolutiontothisproblem
by selectively optimizing essential parameters while leaving the
other parameters unchanged. Of the PEFT techniques that have
been developed, we use low-rank adaptation (LoRA) [24] due
to its adaptation performance. LoRA adds lightweight, fully
connected layers in parallel to speciﬁc layers of the pre-trained
LLM and updates only these added layers.

the LLM transforms each token into embedding vector D. The
output of this module is the hidden states of the textual inputs

the total token length of the text converted to tokens and the

minute or second basis [20]. In other words, weekly patient
counts would provide only about 520 data points after 10 years
of data collection, which can lead to data shortage problems.
The main components of the autoregressive LLM are the
positional encoding layer (PE) and transformer blocks, which
consist of multi-head attention, layer normalization, and feed-
forward layers. Of these layers, we only ﬁne-tune the positional
encoding and layer normalization layers following a standard
training technique [9], [21]. However, unlike previous studies
that conducted various time-series tasks using an LLM with
unimodal data [9], MIFlu forecasts future ILIs with hfuse, a
fused embedding of text and time-series information. Therefore,
the multi-head attention layer also needs to be ﬁne-tuned to
capture new relationships within the fused embedding. This
leads to a signiﬁcant issue: because the multi-head attention and
feed-forward layers contain most of the pre-trained knowledge,
ﬁne-tuning these layers with small-scale ILI data can lead to the
catastrophic forgetting problem in which most of the pre-trained
knowledge is forgotten during the ﬁne-tuning process [22]. To
address this problem, we employ LoRA only to the multi-head
attention layer; therefore, the pre-trained LLM is allowed to
learn new relationships in hfuse without compromising its infer-
ence speed.

Before describing the experiments to evaluate the effective-
ness of MIFlu, we ﬁrst present the datasets, the evaluation met-

The two datasets used in the experiments are
r National-Illness [25]: This dataset includes seven vari-

C. Experimental Details
To compare the forecasting performance of our proposed
model, we consider SOTA models proposed for ILI forecast-
ing. Table IV presents the list of models we compare for na-
tional/regional ILI forecasting and their hyperparameters. These
settings are the same as those reported in previous studies [9],
[14]. The results for the national and regional ILI forecasting
models are taken from [9] and [14], respectively.
In these papers, national ILI has been conducted for long-term
forecasting (L ≥24), while regional ILI has been conducted for
rather short-term forecasting (L ≤24). This is because, due to
the rapid and irregular nature of inﬂuenza spread at the regional
level, regional data are inherently volatile, making short-term
forecasts more practical for immediate public health response.
In contrast, national forecasts based on aggregated data from
multiple regions suppress regional ﬂuctuations and focus on
long-term, persistent seasonal patterns or trends.
Three versions of the ReILIF model used for regional ILI
forecasting have been developed: ReILIFNoC, which uses only
ILI; ReILIFTV, which uses ILI and time-varying exogenous data
(e.g., wind and temperature data); and ReILIFTV/S, which uses
static exogenous data (e.g., population and population density).
We present the results for ReILIFTV/S as the representative of
ReILIF because MIFlu uses textual information that is static
over time [14].
We set the number of training epochs and the learning rate for
MIFlu empirically because the hyperparameters vary depending
on the base model. For our forecasting LLM, we use the ﬁrst K
layers of the original GPT2 according to [9]. Here, K is set at
6 for national ILI forecasting following [9], while K is set at
4 for regional ILI forecasting based on the results presented in
Section VI–D. In these layers, we set low-rank dimension r to
4 following [36]. In addition, for national ILI forecasting, we
set Lp and S to 24 and 2, respectively, according to [9], and for
regional ILI forecasting, we set them to 4 and 2 based on the ratio
of T and Lp and S in national ILI prediction. For the textual input
embedder, we use full GPT2 to align the pre-trained knowledge
with the forecasting LLM (see Section VI–C for more details).
Here, SOTA LLMs like GPT4o cannot be considered because
we cannot modify the structure of those models, and they must
be trained using only text data with a ﬁxed template.
We assess the forecasting performance by calculating the
mean of 10 repetitions of the forecasting results. We implement
the proposed model using Python 3.9.18 with PyTorch 2.1.0 and
a GeForce RTX 3090.

D. Sensitivity Analysis
We also analyze the effect of the hyperparameters on the
forecastingaccuracyofMIFlu.First,wetesttheeffectofwindow
size T of the input time series. Fig. 5(a) and (b) present the
forecasting results when T varies between 10 and 50 for the
US-Region dataset (L = 20) in terms of the RMSE and PCC,
respectively. When the target forecasting time is too far into the
future, it is difﬁcult to achieve high prediction accuracy with a
short input window size (e.g., T = 10). Up until T = 40, a larger
input window size leads to higher forecasting performance,
likely because the forecasting model can utilize more data during
training. However, at T = 50, the excessive input data can lead
to overﬁtting, which degrades forecasting accuracy.

to other tasks, and layers close to the output contain task/data-
speciﬁc information [37]. Therefore, when a pre-trained LLM
is utilized for another task such as time-series predictions, it is
important to select the appropriate number of layers from the

textual input embedder for multimodality, and a LoRA adapter

input variables. In the ablation study, we validate the efﬁcacy of
these core components by removing each component from pure
MIFlu and evaluating the forecasting performance of the model.

section individually. We conduct this study using the National-
Illness data.
